CUGA Web: Privacy Policy

Last updated: 2026-11-23

CUGA Web is a Chrome extension. An AI model that you choose controls browser tabs for you from the side panel. This policy says what data the extension handles, where the data goes, and how you control it.

Summary

  • The publisher of CUGA Web does not collect, receive, store, sell or share any of your data. The extension has no server, no analytics, no tracking and no ads.
  • During a task, the extension sends page content to the model endpoint that you enter in Settings. It sends data to no other place.
  • Settings, skills and saved conversations are stored only in your Chrome profile on your computer.

The extension reads only the tabs it controls for a task. These tabs are in the tab group CUGA and show a border with the text "CUGA is controlling this tab". The extension does not read other tabs and does not read pages when no task runs.

The values of password fields are never read.

To know when a page is still loading data, the extension counts the page's open network requests (fetch and XMLHttpRequest) in the controlled tab. It counts only: it does not read, change, store or send the requests or their content.

Page content can include personal information that is shown on the page, for example names, messages or account data. Do not use CUGA Web on pages that you do not want to send to your model endpoint.

Your model endpoint

You enter the address of an OpenAI-compatible endpoint in Settings, for example your own LiteLLM proxy. The provider of that endpoint processes the data under its own terms and privacy policy. The publisher of CUGA Web has no access to that data.

Storage and deletion

  • Data is stored with chrome.storage.local in your Chrome profile. It is not synchronized and not encrypted by the extension.
  • Delete one conversation or all conversations in the History tab. Turn history off in Settings.
  • Delete skills in the Skills tab.
  • Removing the extension from Chrome deletes all data it stored.

Use of data

The extension uses the data only to perform the task you give it. Data is not sold, not used for advertising, not used to determine creditworthiness or for lending, and not transferred to anyone except the model endpoint you configured.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the new version is published at https://cuga.dev/cuga-web/privacy.html with a new date.
